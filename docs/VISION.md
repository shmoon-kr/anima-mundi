# Anima Mundi — 비전

## 한 줄
AI 에이전트와 사람이 같은 규칙 아래 함께 살아가는 텍스트 세계. 세계는 사람마다 그 사람의 언어로 보이고, 에이전트에게는 구조화된 사건으로 보인다.

## 왜 새로 쓰는가
anima 1단계에서 tbaMUD 위에 에이전트를 돌려 보니, 문제는 하나로 수렴했다: **사람 눈용 문장을 기계가 억지로 읽는다.**
어댑터로 그 문제를 가둘 수는 있었지만, 엔진이 바뀌지 않으면 할 수 없는 것들이 있다.
- 받는 사람마다 다른 언어로 보여 주기 (tbaMUD 는 완성된 영어 문장을 코드 수천 곳에서 바로 보낸다)
- 지각 기반의 공정한 정보 (에이전트가 화면 텍스트로 추측하지 않고, 사람이 보는 것과 정확히 같은 것을 구조로 받는다)
- 결정론·스냅샷·시간 가속 같은 실험과 평가의 기반
- LLM 이 움직이는 NPC, 스스로 자라는 세계

그래서 **엔진은 새로, 세계는 옛것으로** 시작한다. tbaMUD 의 1만 2천 개 방과 30년 다듬어진 규칙을 첫날부터 쓴다.

## 구조
```
 사람 (웹·텔넷·anima play)     에이전트 (anima 런타임)      관전자
        │  WebSocket (엔진 계약 = anima PROTOCOL 1부: 이벤트 + 렌더링된 문장)
 ┌──────┴──────────────────────────────────────────────────────┐
 │ 게이트웨이   WebSocket 서버 · 텔넷 게이트웨이 · 세션·계정 인증       │
 │ 렌더러       이벤트 → 수신자의 언어·관점 문장 (템플릿, 한국어 조사)   │
 │ 지각         누가 무엇을 볼 수 있나 (어둠·투명·거리)                 │
 │ 시뮬레이션   틱 스케줄러 · 결정론 RNG · 규칙(전투·기술·회복·이동)     │
 │ 세계         방·존·몹·물건·상점·리셋 (데이터) · 스크립트 계층        │
 │ 콘텐츠       YAML 데이터 파일 (git, 스키마 검증) + 언어별 번역 파일   │
 │ 영속         계정·캐릭터·세계 상태는 DB (SQLite → Postgres) · 스냅샷  │
 └─────────────────────────────────────────────────────────────┘
 플랫폼 (나중, Python: Django + Strawberry GraphQL)  계정·소유권·에이전트 패키지·순위·다시보기
```
엔진은 WebSocket 하나만 연다. 조회·관리는 플랫폼의 GraphQL, LLM 지휘(MCP)는 anima 런타임의 일이다.

## 다국어
- **모든 출력은 템플릿 + 수신자 언어로 렌더링.** 사건은 언어 중립 슬롯(`{actor}`, `{target}`, `{item}`)으로 흐르다가 소켓 직전에 문장이 된다
- 한국어 조사(은/는·이/가·을/를)는 받침으로 고르는 템플릿 함수. 영어는 대명사·단복수. 어순은 언어별 템플릿이 해결
- 콘텐츠는 **영어가 기본**이고, 번역은 언어별 덧씌움 파일(ID → 번역)로 더한다. 없으면 영어. 처음엔 LLM 일괄 번역으로 채운다 (D11)
- 엔진 메시지는 Project Fluent(`.ftl`) 템플릿
- **명령은 영어** (D17): 대상 키워드도 영어. 대신 한국어 화면에서는 명령의 대상이 되는 자리에 영어 키워드를 괄호로 붙인다 — `구덩이 짐승(beast)이 서 있다` (D18).
  영어 사용자와 한국어 사용자가 같은 방에서 같은 단어(`kill beast`)로 말이 통한다
- 사람이 친 말(say/tell)은 원문 그대로. 받는 사람이 켜는 자동 번역 보기는 선택 기능(번역 표시)
- 캐릭터: **영문 핸들(로그인·명령용, 유일)** + 언어별 표시 이름(선택). 유니코드 핸들은 허용하지 않는다(입력 불가·사칭 문제)
- 표·지도는 문자 폭(한글 2칸)을 계산해 정렬

## 에이전트를 위한 장치
- 지각 단위 이벤트, 고유 ID, 의도 명령(`move`, `attack(id)`) — 텍스트 명령과 함께
- 결정론적 시뮬레이션(시드), 이벤트 로그로 재생
- 세계 스냅샷과 분기: 같은 세계에 다른 에이전트를 넣어 비교 (경기장의 기반)
- 시간 가속 서버(사람 없는 훈련·평가용)
- 행동 비용: 명령마다 소요 시간. 에이전트가 사람보다 빠르게 명령을 쏟을 수 없다
- 공정성: 에이전트는 24시간 돈다. 경제·순위 독식을 막는 장치(시간당 수익 감소, 휴식 보너스, 에이전트 전용/혼합 서버 구분)를 설계 초기부터 고려한다

## 로드맵
1. **최소 세계**: tbaMUD 세계를 읽어 Midgaard 와 초보 지역에서 anima 파티 6인이 사냥할 수 있다 (WebSocket, 영어·한국어 렌더링)
2. **규칙 확장**: 기술·주문 전체, 상점·경제, 퀘스트·특수 동작(스크립트 계층), 텔넷 게이트웨이 완성
3. **에이전트 장치**: 스냅샷·분기·시간 가속, 서버 측 통계, 공정성 장치
4. **플랫폼과 사람**: 계정·소유권, 웹 클라이언트, 관전, 빙의(anima 4단계와 함께)
5. **살아 있는 세계**: LLM NPC, LLM 빌더가 존을 짓고 엔진이 검증, 고유 콘텐츠(상업 이용이 가능하려면 tbaMUD 콘텐츠를 대체해야 한다)
